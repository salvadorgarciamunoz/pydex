API Reference
=============

.. currentmodule:: pydex.core.designer

The :class:`Designer` class is pydex's single public entry point: it
holds the model, the candidate grid, and the model parameters, and
exposes the design criteria, sensitivity evaluation, apportionment, and
estimability methods documented below.
